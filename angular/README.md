# Lawyer Application - Frontend (Angular)

This project is the frontend of the Lawyer application, built with the Angular framework. Below are the step-by-step instructions to run this project on your local machine.

## Prerequisites

Before running the project, make sure you have the following installed on your system:
- **Node.js**: [Download here](https://nodejs.org/) (LTS version is recommended).
- **Angular CLI**: If you don't have Angular CLI installed already, run this command in your command prompt or terminal:
  ```bash
  npm install -g @angular/cli
  ```

## Project Setup and Execution Steps

**Step 1: Navigate to the project folder**
Open your Terminal or Command Prompt and go to the `angular` directory:
```bash
cd angular
```

**Step 2: Install Dependencies**
Run the following command to install all the necessary packages for the project:
```bash
npm install
```

**Step 3: Start the Development Server**
Once the dependencies are installed, use this command to run the project:
```bash
ng serve
```
*(Alternatively, you can also use `npm start`)*

**Step 4: View the Application in your Browser**
After the server starts successfully, open your web browser and go to this URL:
[http://localhost:4200/](http://localhost:4200/)

> **Note:** The app will keep running as long as the command prompt is open and the server is running. If you make and save any changes in the code, the browser will reload automatically.
